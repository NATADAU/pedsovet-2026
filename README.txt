ПЕДСОВЕТ ЦЛП — ГОТОВЫЙ САЙТ ДЛЯ GITHUB PAGES

1. Распакуйте архив.
2. Загрузите всё содержимое папки в корень репозитория GitHub.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку main и папку /(root), затем Save.

Важно: загружайте не саму папку, а все файлы внутри неё.
